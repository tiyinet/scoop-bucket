# 芽朵软件 Scoop Bucket

Windows 软件的 [Scoop](https://scoop.sh) 安装源，收录芽朵软件出品的五款桌面软件：两款桌面宠物游戏、宠物店管理系统、GEO 搜索曝光系统、酒店管理系统。

Windows software bucket for [Scoop](https://scoop.sh). Five desktop applications: two desktop pet games, a pet shop management system, a GEO / AI search visibility platform, and a hotel PMS.

---

## 快速开始 Quick Start

```powershell
# 1. 添加本 bucket (add this bucket)
scoop bucket add yaduo https://github.com/tiyinet/scoop-bucket

# 2. 安装任意一款 (install any app)
scoop install yaduo/mengchong        # 萌宠乐园 桌面宠物养成
scoop install yaduo/mengchongcz      # 萌宠出征 桌面宠物割草
scoop install yaduo/mengchongboss    # 萌宠老板 宠物店管理系统
scoop install yaduo/geobaping        # GEO霸屏 搜索曝光系统
scoop install yaduo/yaduohotel       # 芽朵 酒店管理系统

# 3. 升级 (update)
scoop update; scoop update *
```

要求：Windows 10 / 11，PowerShell 5.1+，Scoop 已安装。所有软件均为免费版（Freeware），静默安装，无需交互。

Requires Windows 10/11 and PowerShell 5.1+. All packages are freeware and install silently.

## 维护说明 Maintenance

每个 manifest 都带 `checkver` 与 `autoupdate`，指向对应项目的 GitHub Releases。上游发布新版本后，运行 `scoop update` 即可拉取；如需刷新版本号，可用 [Excavator](https://github.com/ScoopInstaller/Excavator) 或手动执行 `scoop checkver`。

All manifests use `checkver` / `autoupdate` against the upstream GitHub Releases. Run `scoop update` after a new release, or use Excavator to refresh versions automatically.

Manifest 结构遵循 Scoop 官方规范，安装方式为 NSIS 静默安装（`/S`），安装后可在开始菜单找到程序快捷方式。
